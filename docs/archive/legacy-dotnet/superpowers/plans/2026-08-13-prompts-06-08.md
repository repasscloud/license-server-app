# Prompts 06-08 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement customer contact metadata, product catalogs, and permission-based RBAC in prompt order, then publish one pull request into `dev`.

**Architecture:** Keep issuance invariants in `LicenseStore` and PostgreSQL, catalog operations in a focused service, and authorization definitions in centralized permission/role types. UI and HTTP endpoints remain thin adapters over the shared services.

**Tech Stack:** .NET 10, ASP.NET Core Razor Components and Identity, EF Core, Npgsql/PostgreSQL, xUnit.

**Spec:** `docs/prompt-06.md`, `docs/prompt-07.md`, and `docs/prompt-08.md`

## Global Constraints

- Implement prompts strictly in the order 06, 07, 08.
- Preserve the existing unstaged `global.json` modification and exclude it from all commits.
- Retain immutable signed snapshots and immutable historical product-code snapshots.
- Use field-level request errors for forged controlled values.
- Require authorization at pages, endpoints, and mutation service boundaries.
